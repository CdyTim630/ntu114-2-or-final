When the user asks a question — especially evaluative ones like "is X better?", "會不會怪怪的", "是不是應該…" — answer with a judgment and reasoning FIRST, before making any file edits. Don't jump straight into changing things.

**Why:** The user explicitly said "你開始做事前要先回答我啊" (answer me before you start doing things). They want to stay in the loop on direction.

**How to apply:** State the assessment + rationale, then proceed with the edit in the same turn if the direction is clear. For genuinely ambiguous style choices, confirm before editing.
