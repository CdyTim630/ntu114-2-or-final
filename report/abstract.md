# 200-Word Project Abstract (Chinese, to match video presentation)

本研究將「便利商店最佳化餐食推薦」形式化為一含優惠組合、含個人化營養限制、餐型結構與分層多樣性懲罰之混合整數線性規劃 (MILP)。以 Mifflin–St Jeor 公式將使用者輸入（性別、年齡、身高、體重、活動量、健康目標、情境模式）轉換為單餐熱量、蛋白質、脂肪、碳水、糖與鈉之限制；模型同時決定哪些商品以單品方式選入、哪些優惠組合啟用，並以鬆弛變數處理過嚴條件下的可行性問題。為避免對商業 solver 之依賴，我們自行設計 GRASP-LS（貪婪隨機建構 + 局部搜尋 + 多重啟動）啟發式，並以 Gurobi 為基準量化 optimality gap。實驗資料透過全家便利商店官方 API 即時爬取：食在購安心食品履歷取得 581 項商品官方營養標示，過濾家庭份後為 488 項；價格為 124 項鮮食促銷頁實際分級價 + 457 項市售行情校正價。實驗以 18 個真實使用者例題 + 30 個隨機例題驗證：MILP 全數求得全域最佳解；GRASP-LS 在真實例題 100\% hard-feasible、平均 optimality gap 為 7.1\%（12/18 達最佳），隨機例題平均 gap 4.9\%（28/30 可行）；最簡單貪婪法因餐型結構與鈉硬上限，在真實例題 0\% 可行。另以 Gurobi 解池量化「多樣性的代價」，並實作 Flask 互動式 web 應用，將模型部署為可即時推薦的工具。
