# 200-Word Project Abstract (Chinese, to match video presentation)

本研究將「便利商店最佳化餐食推薦」抽象為一含優惠組合、含個人化營養限制與含歷史多樣性懲罰之混合整數線性規劃 (MILP)。以 Mifflin–St Jeor 公式將使用者輸入（性別、年齡、身高、體重、活動量、健康目標、情境模式）轉換為單餐熱量、蛋白質、脂肪、碳水、糖與鈉之限制；模型同時決定哪些商品以單品方式選入、哪些優惠組合啟用，並以鬆弛變數處理過嚴條件下的可行性問題。為避免對商業 solver 之依賴，我們自行設計 GRASP-LS（貪婪隨機構造 + 局部搜尋 + 多重啟動）啟發式，並以 Gurobi 為基準量化最佳化差距。實驗數據透過三個全家便利商店官方 API 即時爬取：食在購安心食品履歷取得 581 項商品官方營養標示；鮮食促銷頁與全家行動購 GraphQL 取得 1,918 條真實零售價，覆蓋 66.1\% 商品。實驗以 18 個真實使用者例題 + 30 個隨機例題（共 48 情境）驗證：GRASP-LS 在所有 48 情境均達 hard-feasible，平均 optimality gap 為 3.5\%（真實）／2.4\%（隨機）；最簡單貪婪法在 33\% 真實情境下不可行，gap 可達 400\%。最後本研究實作了 Flask 互動式 web 應用，將模型部署為可即時推薦的工具。
